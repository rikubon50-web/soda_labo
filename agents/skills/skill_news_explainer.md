# Skill: ニュース解説

## 概要

AI・ビジネスニュースを、ターゲット読者（行動したい20代）向けに噛み砕いて解説する。

## 使用するAgent

Writer（メイン）、Planner（切り口設計に使用可）

## いつ使うか

- ニュース解説記事を書くとき
- 「結局何がすごいのか」を整理したいとき

## 入力（必要な情報）

- ニュースの概要（何があったか）
- ソース（URLまたは要約）
- 読者に伝えたい核心（任意）

## 処理手順

以下の5段構成で書く：

1. **何が起きたか**（事実を1〜2文で）
2. **なぜ重要か**（見逃せない理由）
3. **誰が影響を受けるか**（具体的に）
4. **実際どういう意味か**（身近な言葉に翻訳）
5. **次に何を見ればいいか**（読者が取るべき行動・注目点）

## 出力形式

```
【ニュース解説】

■ 何が起きたか
___

■ なぜ重要か
___

■ 誰が影響を受けるか
___

■ 実際どういう意味か
___

■ 次に見るべきこと
___
```

## 品質チェック

- [ ] ヘッドラインの要約で終わっていないか（解釈が入っているか）
- [ ] 「AIが進化しています」で始まっていないか
- [ ] 読者が「で、自分はどうすればいい？」に答えられる内容か
- [ ] 事実と意見が混ざっていないか（意見は明示する）
- [ ] 確認できていない数字・データを断定で書いていないか
