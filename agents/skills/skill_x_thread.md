# Skill: Xスレッド設計

## 概要

1つのテーマをX投稿3本セットに設計する。3本が独立して読めつつ、順番に読んだときに意味が深まる構成にする。

## 使用するAgent

Writer（メイン）

## いつ使うか

- note記事のX展開をするとき
- X単独コンテンツとして3本セットを作るとき

## 入力（必要な情報）

- テーマ（何について投稿するか）
- 核心メッセージ（最も伝えたいこと）
- note記事があれば概要

## 処理手順

**3本は独立投稿（スレッド不可）。時間差で出すため、各投稿が単体で完結すること。**

1. **朝（1本目）**：主張・学び・強い意見。断言で始める。読者の思い込みに反する内容が強い。CTA不要。
2. **昼（2本目）**：軽めの気づき・日常・具体的な小話。重くしない。気軽に読めるトーン。
3. **夜（3本目）**：共感・ストーリー・質問系。「あなたはどう？」で終わるか、読者が自分事にできる締め。**117字以内**で書く（note記事URLがシステムで自動追加されるため）。

**各投稿のルール：**
- 140字以内（厳守）
- 改行は意味のある場所だけ
- 1投稿1メッセージ（詰め込まない）
- 前の投稿を前提にしない（単体で読んで意味が通る）

## 出力形式

```
【X投稿 3本】

朝（1本目）：
___
（___字）

昼（2本目）：
___
（___字）

夜（3本目）：
___
（___字）
```

## 品質チェック

- [ ] 全投稿140字以内か
- [ ] 各投稿が単体で意味が通るか（前の投稿を前提にしていないか）
- [ ] 朝は断言・強い主張になっているか
- [ ] 昼は軽く読めるか（重くなっていないか）
- [ ] 夜に共感・質問・誘導の要素があるか
