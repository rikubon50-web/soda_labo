# Skill: フック作成

## 概要

記事・動画・X投稿の冒頭を、読者が「続きを読まずにいられない」状態にする。

## 使用するAgent

Writer（メイン）、Editor（フック強化時）

## いつ使うか

- note記事の書き出しが弱いとき
- 動画台本の冒頭3秒が決まらないとき
- X投稿の1本目が引きつけないとき

## 入力（必要な情報）

- 記事・動画のテーマ（何について書くか）
- 核心メッセージ（一番伝えたいこと）
- 媒体（note / 動画 / X）

## 処理手順

以下のパターンから最も合うものを選んで書く：

**パターンA：逆説**
読者の「当たり前」を裏切る。
例：「AIに記事を書かせた。でも一番難しかったのは、AIに指示を出すことだった。」

**パターンB：宣言**
何をやるか・何が起きたかを言い切る。曖昧にしない。
例：「AIでメディアを動かすことにした。今日がその初日だ。」

**パターンC：問い**
読者が「そうかも」と思う問いを投げる。答えは本文で出す。
例：「毎日投稿しても伸びない。それ、努力の問題じゃないかもしれない。」

**パターンD：数字・事実**
具体的な数字や出来事で始める。
例：「指示書に4行追加しただけで、出力の質が変わった。」

## 出力形式

```
【フック案】

案1（パターン___）：___
案2（パターン___）：___
案3（パターン___）：___

推奨：___（理由：___）
```

## 品質チェック

- [ ] 「AIが急速に進化する現代において」で始まっていないか
- [ ] 読んだ人が「次の行を読みたい」と思うか
- [ ] 抽象的すぎないか（具体的な状況・行動・数字があるか）
- [ ] 媒体に合った長さか（動画：1文/X：1〜2文/note：2〜3文）
