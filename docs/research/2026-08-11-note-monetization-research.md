## 2. noteのアルゴリズム: 一次情報が構造的に優遇される（公式一次情報）

- **推しアルゴリズムの優先順位**（note CXO深津氏、2026-01-21公表）: ①人間の一次体験 → ②一次情報のAI編集 → ③ユニークなAI生成 → ④量産型。評価軸は「一次性・独自性・検証可能性」
- **レコメンド刷新**（note公式、2026-02-12）: LLM自動タグ付けで記事単位配信に。カテゴリ内インプレッション4.3倍・PV2.2倍。**「フォロワー数が少なくても面白い記事は届く」と公式が明言**
- 流入の73%がnote内回遊+検索。SNS経由は8%まで低下（3年で20%→8%）
- **note経由の生成AI（ChatGPT等）流入は検索期待値の約4倍** — 一次情報はAIの回答にも引用される
- 公式推奨の発見施策: 見出し画像（ビュー・スキに数十%差）/ タグ5個を4観点で / 冒頭50字リード文 / 外部配信許諾ON（SmartNews・LINE NEWS配信対象）/ お題企画・コンテスト参加

## 3. build-in-public（実数公開）の実勢: 数字だけでは伸びない

**刺さる条件**: (a) 再現可能なノウハウとセット (b) マイルストーン性のある回 (c) 検証可能性。
**刺さらない条件**: 数字だけの垂れ流し（「収益報告は話半分」という読者リテラシーが定着済み。相互いいね水増しへの不信もある）。

# 戦略への示唆（統合結論）

1. **柱1（毎朝のニュース解説）は成長ドライバーにならない**。LOADINGの実例とアルゴリズム優先順位（AI生成は3〜4位）が二重に示している。役割を「習慣・信頼・素材製造」に再定義し、成長期待を下ろす
2. **週1の「今週の構造まとめ」（論点見出し+編集）を追加する** — データで確認できた唯一の勝ち型（チャエン型）
3. **柱2（運営実録）は「数字+再現手順+検証可能性」の三点セット構成が必須**。数字垂れ流しは飽きられることが実証済み。SODAの武器は全ログ・全コード・全プロンプトが実在する完全な検証可能性 — 「話半分」ジャンルで唯一疑いようのない発信者になれる
4. **初商品は¥300〜500**で購入実績を作ってから段階値上げ。形式は「プロンプト集」ではなく「SODAを作った再現手順+実データ」
5. **無料施策の即実行リスト**: 外部配信許諾ON（要設定確認）/ 冒頭50字リード文をwriter.mdに追加 / お題企画・コンテストの定期チェック（見出し画像・タグ5個は対応済み）
6. AI活用はnoteの急成長ジャンル1位であり、市場自体は追い風。勝負は「量産AI記事」に分類されない一次性の確保にかかっている
