# AIニュース解説週間 設計ドキュメント

作成日：2026-04-29  
期間：2026-04-29 〜 2026-05-05（7日間）

## 背景・目的

2026-04-26（日）のX投稿がIMP:389を記録した。  
同日の投稿はGoogle Cloud AIエージェント投資（1,000億超）を題材にした外部ニュース解説で、他の日（平均50〜80 IMP）の約5倍の数字を出した。

この成功を再現・検証するため、1週間「外部AIニュースを起点にした解説投稿」を毎日3本続ける実験を行う。

**ゴール：7日間の平均IMPを150以上にする**

---

## 実験ルール

- 毎日必ずAIニュースを1本選んで投稿する（ネタが弱い日も見送りなし）
- ハッシュタグなし
- note URLなし
- ソースURLは全3本に入れる
- CEOが下書きを確認してから投稿する

---

## 投稿フォーマット（1日3本）

### 朝（1本目）：数字・事実フック + ソース

```
[企業名/固有名詞]が[具体的な数字・事実]を[した/発表した]。
[それが普通と何が違うのかを1文で]。
[今日の昼か夜に詳しく書く、という予告1文]。

ソース：[URL]
```

目安：3〜4文、100字前後。短く驚かせる。

### 昼（2本目）：構造解説 + ソース

```
[ニュースの核心を問い形式で1文]

・[背景・なぜ今なのか]
・[具体的に何が起きているか]
・[他のプレイヤーとの違い・比較]

[締め：「要するにこういうことだ」の1文]

ソース：[URL]
```

目安：150〜250字。長文OK。箇条書き可。

### 夜（3本目）：読者への示唆 + ソース

```
[今日のニュースを受けて、20代・これから動く人に何が変わるか]
[具体的に「何をすればいいか」or「何に気づくべきか」を1〜2点]

ソース：[URL]
```

目安：150〜200字。説教・煽りは禁止。

---

## Writer指示書への追加内容

`agents/writer.md` の「X投稿のフォーマット」セクションに以下を追加する。

```
## X投稿 ニュース解説モード

CEOから「ニュース解説」と指定された日はこのフォーマットを使う。
通常モードのフォーマット（主張型・Day N・AIそれって本当？）は使わない。

朝（1本目）：数字・事実フック
 - 企業名・数字・事実で1〜2文。驚きがある情報を先頭に。
 - 「今日の昼か夜に詳しく書く」の予告1文。
 - 末尾に「ソース：[URL]」を入れる。
 - 目安：3〜4文。

昼（2本目）：構造解説
 - 「〇〇とは何か・なぜ今か」を問い形式で始める。
 - 背景・事実・他社比較を箇条書き3点で整理。
 - 「要するに〜」で締める。
 - 末尾に「ソース：[URL]」を入れる。
 - 目安：150〜250字。

夜（3本目）：読者への示唆
 - 今日のニュースを受けて「20代に何が変わるか」。
 - 「何をすればいいか」or「何に気づくべきか」を1〜2点。
 - 末尾に「ソース：[URL]」を入れる。
 - 目安：150〜200字。

ソースURLについて：
 通常モードでは外部リンク禁止だが、ニュース解説モードでは
 ソース明示のためURLを入れる。例外として扱う。
```

---

## ニュース収集

既存パイプラインのStep 0（AIニュース自動収集）を使う。  
毎日のCEO朝会議でStep 0の出力から当日のネタを1本選ぶ。

---

## 承認フロー

1. Step 0でニュース収集
2. CEOがネタを1本選ぶ
3. Writerがニュース解説モードで下書き3本を作成
4. CEOが確認・修正
5. 投稿（朝・昼・夜に時間差で）

---

## 計測ルール

- **計測タイミング**：投稿から24時間後にX analyticsで確認
- **記録場所**：`logs/daily/YYYY-MM-DD_post_analysis.md` の数値サマリー
- **週次集計**：実験終了後（2026-05-05）に `logs/weekly/2026-04-29_news_week_result.md` を作成

### 週次集計ファイルの内容

```
- 各日の朝・昼・夜のIMP
- 1日合計IMP
- 7日間の平均IMP
- 最もIMPが高かった投稿とその特徴
- 最もIMPが低かった投稿とその分析
- 継続するか・変更するかの判断
```

### 成功基準

**7日間の平均IMP ≥ 150**

（現ベースライン：平均50〜80 IMP/日。Apr 26の389を除いた参考値）

---

## 実験後の判断基準

| 結果 | 判断 |
|------|------|
| 平均IMP ≥ 150 | ニュース解説を軸に継続。他のシリーズと並走 |
| 平均IMP 80〜150 | 一部ネタの選び方を変えて継続検証 |
| 平均IMP < 80 | フォーマット・タイミングを見直し |
