## 設定手順

### プロフィール設定
1. Xを開く → プロフィール → 「プロフィールを編集」
2. 「自己紹介」欄に上記テキストを貼る
3. 「保存」

### 固定ポスト設定
1. 上記テキストをツイートとして投稿する
2. 投稿したツイートの「︙」→「プロフィールに固定」
3. 設定完了
