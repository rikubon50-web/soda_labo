## 固定ポスト原稿

```
AIニュースを毎日3本、構造解説しています。

このアカウントの型：
[1] 起きた事実を1〜2文（数字＋主体）
[2] 「なぜそうなるか」を箇条書き2〜4点
[3] 一行で示唆して終わる

たとえば一本：

AnthropicがOpenAIのARRを抜いた。$30B対$24B。
なぜか。性能勝負ではなく、選ばれる基準が変わった。
・大企業：安全性・コンプラ適合性
・個人：速度・UX
軸が分かれた瞬間、ChatGPTの先行優位は通用しなくなった。

朝・昼・夜で別ニュースを単独完結で。
毎日のAIの動きを「なぜ起きているか」で読みたい人にどうぞ。

深掘りはnote → https://note.com/sodalabo
```

**ポイント**:
- 「説明 → 型のメタ → 実例 → 締め」の4段構成で初見の読者に読み方を渡す
- 実例は5/07の Anthropic-Blackstone 系（35 IMP 実績）の改稿版で、型の質を証明する
- 末尾の note 誘導は1行のみ（プロフィールと一貫させる）

## 設定手順

### プロフィール設定
1. Xを開く → プロフィール → 「プロフィールを編集」
2. 「自己紹介」欄に上記テキストを貼る
3. 「保存」

### 固定ポスト設定
1. 上記テキストをツイートとして投稿する
2. 投稿したツイートの「︙」→「プロフィールに固定」
3. 設定完了
