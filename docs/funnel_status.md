# SODA note導線ステータス

このファイルはnote内の読者獲得導線の設置状況を追跡する。
run_list_check.py が毎日21:15に自動確認する。手動で変更した場合もここを更新すること。

## 方針（2026-08-11 X撤退に伴い全面改訂）

読者獲得はnote内で完結させる。指標はnoteフォロワー数（起点: 5人 / 2026-08-11）。

---

## 1. マガジン3誌が存在し、毎日の記事が追加されているか

**状態**: 🔧 整備中（初期整備タスクで✅化する）
**内容**: config/magazines.json にマガジン3誌（Task 1）を登録し、毎日の記事を該当誌に追加する（Task 4）
**チェック方法**: 自動（logs/daily/{ds}_magazine.txt の誌名が config/magazines.json にあるか）
**次のアクション**: Task 1・4完了後、実際に数日分の記事が追加されるのを確認してから✅化する

---

## 2. note記事末尾にフォローCTAがあるか

**状態**: ✅ 設定済み（2026-08-11〜、writer.md定型文）
**内容**: 「フォロー」を含む定型のフォロー誘導文をnote記事末尾に配置
**チェック方法**: 自動（note記事末尾400字をスキャンし「フォロー」を検出）
**次のアクション**: なし（継続監視のみ）

---

## 3. プロフィールがニュースメディアの価値提案になっているか

**状態**: 🔧 整備中（初期整備タスクで✅化する）
**内容**: noteプロフィール文をニュースメディアとしての価値提案（何が読めるか・誰向けか）に書き換える
**チェック方法**: 手動確認（API確認は初期整備後に✅化し、以後はこのファイルの状態を基準にする）
**次のアクション**: プロフィール文言を作成し、note側に反映後にこの欄を✅にする

---

## 4. サイトマップ記事が固定表示されているか

**状態**: 🔧 整備中（初期整備タスクで✅化する）
**内容**: マガジン一覧・note内導線をまとめたサイトマップ記事をプロフィールに固定表示する
**チェック方法**: 手動確認（API確認は初期整備後に✅化し、以後はこのファイルの状態を基準にする）
**次のアクション**: サイトマップ記事を作成し、note プロフィールに固定表示後にこの欄を✅にする
