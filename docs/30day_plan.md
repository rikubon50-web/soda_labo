# SODA 最初の30日プラン

## 目的

- 量を出して、反応があるテーマを見つける
- 継続の習慣を作る
- SODAの声と世界観を確立する

## 数値目標（最低ライン）

| 媒体 | 目標 |
|------|------|
| note | 20本（週5本ペース） |
| X投稿 | 60本（1テーマにつき3本 × 20） |
| 短形動画台本 | 10本 |

## 週別テーマ配分

### Week 1（Day 1〜7）：AI実験
AIに仕事をやらせた記録を中心に出す。
実験・失敗・気づきをそのまま記事にする。

- 例：「Claudeに1日の業務を全部任せてみた」
- 例：「AIで記事を自動生成したら何が起きたか」
- 例：「Claudeを5役に分けて会社ごっこをした話」

### Week 2（Day 8〜14）：ニュース解説
AI・テック・ビジネスニュースを噛み砕く。
「結局これってどういうこと？」を答える記事。

- 例：「OpenAIの新モデル、普通の人に何が変わるか」
- 例：「AIスタートアップが急増している本当の理由」

### Week 3（Day 15〜21）：成長・行動
20代・学生向けの行動戦略と思考整理。
自分の経験や視点を出す。

- 例：「同世代がAIで動き始めている。あなたはまだ見てるだけ？」
- 例：「学生のうちにやっておけばよかった3つのこと」

### Week 4（Day 22〜30）：まとめ・振り返り・次の設計
- Week 1〜3の反応を見て、当たったテーマをピックアップ
- シリーズ化できるテーマを1〜2本決める
- Phase 2（低単価商品化）への足がかりを考える

## 毎日のルーティン（最小構成）

```
1. 今日のテーマを決める（5分）
2. 企画案を3本出す（10分）
3. 1本を選んでnote下書きを作る（30〜60分）
4. X投稿3本を作る（15分）
5. 公開・記録（10分）
```

合計：1〜1.5時間

## 30日後の評価基準

以下を確認して次のフェーズを設計する：

- [ ] どのテーマが一番反応があったか
- [ ] どの媒体（note / X / 動画）が伸びやすかったか
- [ ] シリーズ化できる企画はどれか
- [ ] 読者層は想定通りだったか
- [ ] Phase 2に進めるテーマがあるか

## 禁止事項（この30日間）

- 完璧を目指して公開を遅らせない
- デザインやフォーマット整備に時間をかけすぎない
- 反応がなくても1週間で方向転換しない（データが少なすぎる）
